## STEP 0. まず自分で試す（お金いらない・3分）

すでに池本さんのPCには入っていますが、念のため。

1. Chromeのアドレスバーに `chrome://extensions` と入力してEnter

## STEP 3. 入力内容（そのままコピペしてください）

### ■ 説明（Description）

```
いま見ているWebページを、スクロールしないと見えない一番下まで丸ごと1枚の画像（PNG）とPDFで保存できる無料ツールです。

■ 使い方は2通り。どちらもワンアクション
・ページ右下のピンクの「PATTI SHOT」ボタンをクリック
・キーボードなら Ctrl + Shift + S

■ こんなときに
・長いWebページの記録を、切れ目のない1枚で残したい
・会議資料・検索結果・申請画面などを、あとから見返せる形で保存したい
・Webページを丸ごとAIに読ませたい

■ 特長
・スクロールが必要な長いページも、下まで全部1枚に
・固定ヘッダーが何度も写り込まない、継ぎ目のないきれいな仕上がり
・実際の中身の高さを測って撮るので、巨大な余白ができません
・画質は1倍・2倍・3倍から選べます（2倍なら文字もくっきり）
・PNG / PDF / 両方 を選んで保存
・ログインが必要なページも、いつも使っているブラウザのままなのでそのまま撮れます

■ プライバシー
撮影した画像や閲覧内容を外部に送信することは一切ありません。すべてあなたのパソコンの中だけで完結します。広告・解析も入っていません。ソースコードはGitHubで全公開しています。

制作：STUDIO PATTI（合同会社スタジオパッチ）
```

### ■ 権限の理由（各権限の欄に1つずつコピペ）

| 権限 | 貼り付ける文章 |
|---|---|
| `debugger` | ページ全体を1枚の画像として高画質で取得するために、Chromeの標準的なスクリーンショット機能（Page.captureScreenshot）を使用します。利用者が撮影を指示したときだけ接続し、撮影後ただちに解除します。取得した画像は利用者のパソコンに保存するだけで、外部送信は一切ありません。 |
| `downloads` | 撮影した画像・PDFを、利用者のダウンロードフォルダ内「PATTI SHOT」フォルダに保存するために使用します。 |
| `storage` | 保存形式（PNG/PDF/両方）と画質倍率（1x/2x/3x）の設定を記憶するためだけに使用します。閲覧履歴等は保存しません。 |
| `scripting` | 撮影ボタンを表示し、ページの実際の高さを測定して撮影範囲を決めるために使用します。 |
| `activeTab` | 利用者が撮影を指示したタブに対してのみ処理を行うために使用します。 |
| `offscreen` | 取得した画像をつなぎ合わせ、PNG／PDFに変換する処理を行うために使用します。 |
| **ホスト権限**（`<all_urls>`） | 利用者はどのWebサイトでも撮影したいため、対象サイトを限定できません。撮影ボタンを表示し、利用者が撮影を指示したページのみを処理します。閲覧内容の収集・送信は一切行いません。 |

> 💡 `debugger` と `<all_urls>` は、Googleが特に厳しく見る2つです。
> 上の文章は「なぜ必要か・いつ使うか・データを送らないこと」を明記してあるので、そのまま貼ってください。

## STEP 4. 審査に出す

1. 左メニューの各タブに**緑のチェック**が付いているか確認（付いていない＝未入力の欄があります）
2. 右上の「**審査のために送信**」をクリック
3. 公開範囲は「**一般公開**」を選んで確定

### 審査にかかる期間の目安（2026年7月現在）
- **多くは数日**。ただし**数週間かかることもあります**
- PATTI SHOTは `debugger` と `<all_urls>` を使う＝**人間の目でじっくり見られる側**なので、
  1〜2週間は見ておくと気が楽です
- **3週間を過ぎたら**Googleのサポートに問い合わせできます（そのとき私が文面を作ります）

審査に通るとメールが届きます。**通ったら教えてください。**
配布ページ（ikemotodir.github.io/patti-shot/）を「ストアからインストール」に切り替えます。
そうすると **利用者のアプリは以後、全自動で更新される**ようになります。
