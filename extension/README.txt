PATTI SHOT（Chrome拡張機能）
============================
いま見ているページを、一番下まで丸ごと1枚のPNG/PDFで保存します。
無料・STUDIO PATTI製。撮影データはあなたのPCの中だけに保存されます。

【インストール（初回だけ・1分）】
1. このzipを展開して、フォルダごと好きな場所に置く
   （例: ドキュメントの中。あとで動かさない場所がおすすめ）
2. Chromeで chrome://extensions を開く
3. 右上の「デベロッパー モード」をON
4. 「パッケージ化されていない拡張機能を読み込む」→ 1のフォルダを選ぶ
5. 撮りたいページを開くと右下にピンクの「PATTI SHOT」ボタンが出ます

【使い方】
・ピンクのボタンを押すだけ（Ctrl+Shift+S でもOK）
・保存先: ダウンロード \ PATTI SHOT フォルダ（PNG / PDF / ログ）
・保存形式や画質は、ツールバーのPATTI SHOTアイコンから変更できます

【更新のしかた】
新しい版が出ると、ツールバーのPATTI SHOTアイコンを押した画面に
「新しい版があります」と表示されます。
1. 表示のリンクから新しいzipをダウンロード
2. 展開して、今のフォルダの中身をすべて入れ替える
3. chrome://extensions でPATTI SHOTの「更新」ボタン（🔄）を押す
※Chromeの仕様上、zip版は自動では置き換わりません。
　全自動更新に対応したChromeウェブストア版は準備中です。

【create_shortcut.bat】
ダブルクリックすると、この拡張機能フォルダへのショートカットを
デスクトップに作ります（更新のとき、フォルダをすぐ開けて便利です）。
