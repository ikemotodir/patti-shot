PATTI SHOT プライバシーポリシー

最終更新: 2026年7月26日

PATTI SHOT は、利用者のデータを一切収集しません。

撮影した画像・PDF、閲覧しているページの内容やURL、その他いかなる情報も、 外部のサーバーに送信することはありません。すべての処理は、利用者のパソコンの中だけで完結します。

収集する情報

ありません。個人情報・閲覧履歴・位置情報・認証情報などを収集、保存、送信、販売することは一切ありません。

保存されるもの（すべて利用者のパソコン内）

  • 撮影した画像・PDF：ブラウザのダウンロードフォルダ内「PATTI SHOT」フォルダに保存されます
  • 設定：保存形式（PNG / PDF / 両方）と画質倍率（1x / 2x / 3x）のみを、 ブラウザのローカル保存領域に記録します（次回も同じ設定で使うためです）

権限を使う理由

  • debugger：ページ全体を高画質で撮影するために、ブラウザの標準的な撮影機能を利用します。 撮影のときだけ使い、終了後はすぐに解除します
  • downloads：撮影した画像・PDFをダウンロードフォルダに保存するために使います
  • storage：上記の設定（保存形式・画質）を覚えておくために使います
  • scripting / activeTab / ホストへのアクセス：撮影ボタンを表示し、 ページ全体の高さを測って撮影するために使います。利用者が撮影ボタンを押したページに対してのみ動作します
  • offscreen：撮影した画像をつなぎ合わせてPNG / PDFにする処理に使います

第三者への提供

ありません。広告・解析（アナリティクス）・トラッキングの類は一切組み込んでいません。
